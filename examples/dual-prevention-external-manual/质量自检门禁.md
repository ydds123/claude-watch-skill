# 图片质量自检门禁（内部文件）

本文件记录对外操作手册的图片自检流程和本次执行结果。**未通过门禁的图片和章节不得进入发布流程。**

## 1. 门禁流程（每次产出图片后必须执行）

| 步骤 | 检查内容 | 通过标准 | 工具/方式 |
|---|---|---|---|
| 0 取帧 | 连拍、平台期、状态断言 | 帧处于 UI 稳定态；弹窗区域断言通过 | `stable_frame.py` 证据 |
| 8 资产版本 | 文件名/引用带版本号，manifest 哈希一致 | 引用文件 = manifest 最新版本 | `assets/manifest.json` |
| 1 取图 | 截图来源 | 帧来自原始录制视频，非二次压缩图片 | ffmpeg 定点抽帧（原生 1920×1080） |
| 2 裁剪 | 去桌面、浏览器外壳、任务栏 | 只保留系统页面；无地址栏、无分享水印 | `annotate.py` 按 JSON 裁剪 |
| 3 可读性 | 无遮挡、浮窗清晰 | 无关浮窗不遮挡主体；浮窗完全展开、不透明、文字可读 | 逐张目检（弃用规则见下） |
| 4 内容核对 | 图片与章节/图注一一对应 | 页面标题、tab、弹窗标题与图注一致 | 标题条复核（`check_images.py --title-out`） |
| 5 清晰度 | 分辨率、文字可读 | 成品宽度 ≥ 1400 px；关键文字可辨认；无放大模糊 | `check_images.py --min-width 1400` |
| 6 引用校验 | 正文引用的图片全部存在 | 引用数 = 图片数，无缺失、无重复引用 | `check_images.py` 报告 |
| 7 一致性 | 图注、正文步骤、编号一致 | 图注描述与正文操作步骤对应 | 人工核对 + 报告留档 |

任一步不通过：返回修正，重新执行完整门禁，不能只补单项。

**直接弃用的画面**：无关浮窗（弹窗/抽屉/气泡）遮挡页面主体；浮窗半透明、加载中、动画中间态导致文字不可读；鼠标、输入法、通知遮挡关键字段；表格只有“暂无数据”而空态不是讲解对象；页面切换的过渡帧。遇到即换帧或重录，不靠放大锐化补救。

## 5. 重新生成与复检命令

```powershell
# 1) 生成图片（Pillow 裁剪）
python "<skill-dir>\scripts\annotate.py" `
  "<project-dir>\assets\annotations\manual.json"

# 2) 门禁检查 + 标题条复核图
python "<skill-dir>\scripts\check_images.py" `
  --doc "<project-dir>\双重预防机制操作手册.md" `
  --manifest "<project-dir>\assets\manifest.json" `
  --require-page-id --min-width 1400 `
  --report-out "<project-dir>\运行产物\gate\image-gate.json" `
  --title-out "<project-dir>\运行产物\gate\titles.jpg"

# 3) 文档门禁（引用/版本/page_id/标注策略/对外结构）
python "<skill-dir>\scripts\doc_lint.py" `
  --doc "<project-dir>\双重预防机制操作手册.md" `
  --manifest "<project-dir>\assets\manifest.json" `
  --images-dir "<project-dir>\assets\images" `
  --require-versioned --require-page-id --external `
  --annotations "<project-dir>\assets\annotations\manual.json" `
  --report-out "<project-dir>\运行产物\gate\doc-lint.json"
```
