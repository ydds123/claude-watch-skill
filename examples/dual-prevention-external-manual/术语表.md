# 术语表

对外手册中同一概念只使用一个名称，新增术语需先在此登记。

| 术语 | 说明 |
|---|---|
| 双重预防机制 | 风险分级管控与隐患排查治理双重预防工作体系 |
| 双预防任务 | 由属地应急管理部门下发、企业按期执行并上报的检查任务 |
| 风险分析对象 | 双重预防机制分析的基础对象，通常对应一个区域、装置或场所 |
| 风险分析单元 | 风险分析对象下的细分单元，一个对象可包含多个单元 |
| 风险等级 | 重大风险、较大风险、一般风险、低风险四类 |
| 危害因素 | 可能导致事故的危险有害因素 |
| 管控措施分类 | 对管控措施进行分级归类的字典数据，巡检检查项目需关联 |
| 排查库 | 以树形结构维护排查对象、排查内容和选择依据的库 |
| 风险安全清单 | 由风险分析对象和单元自动形成的风险报表 |
| 分级管控清单 | 由巡检计划大表导入后形成的分级管控报表 |
| 风险四色图 | 在企业平面图上按风险等级标注风险分布的图 |
| 巡检点 | 任务下发的最小点位 |
| 双预防巡检点 | 执行双预防任务、需关联风险分析单元的巡检点 |
| 日常巡检点 | 企业自身设备日常巡检使用的点位，不参与双预防评估 |
| 签到方式 | 扫码签到、NFC 签到、人员定位签到 |
| 巡检计划 | 按周期向巡检点推送任务的计划 |
| 检查项目 | 巡检点下需要检查的具体事项 |
| 检查标准 | 检查项目的判定标准，含检查类型、单位、合格区间 |
| 隐患治理 | 隐患登记、审批、处理、闭环的流程 |
| 异常上报 | 现场发现异常时的上报入口，支持实时和批量提交 |
| 奖惩绩效 | 按排查任务和隐患治理结果自动计算积分与金额的考核功能 |
| 三率一量 | 面向园区数据申报的统计指标 |
| 任务清单 | 承接上级派发任务并形成具体执行任务的页面 |
| 包保履职 | 重大危险源包保责任人的履职任务与完成率统计 |
