# claude-watch 使用说明与录制语料规范

面向同事的实操手册。目标：把一段培训/演示视频，稳定产出**可交付的图文材料**（笔记、内部功能图文、对外操作手册），并且截图可追溯、可过门禁。

---

## 一、这个 skill 能做什么

| 模式 | 产出 | 适用场景 |
|---|---|---|
| `notes` | 带时间戳的 `notes.md` | 教程、课程、讲座、技术分享 |
| `product-guide` | 证据驱动的内部功能图文 | 内部培训、交付团队、售前了解功能 |
| `external-manual` | 对外操作手册（无时间戳/无内部信息，截图带脱敏+标注） | 给客户的操作手册、上线交付材料 |

**不适用**：视频剪辑/转码、一次性转写摘要、PPT/营销设计。

---

## 二、使用方式（三步）

```bash
# 1. 生成转写 + 帧 + 证据
python3 scripts/watch.py "<视频URL或本地路径>" --mode external-manual

# 2. 看证据，选稳定帧（product 模式默认已输出 frame-stable/）
#    - frame-stable/          平台期选帧（推荐直接用于成品）
#    - frame-candidates/      动作前后候选帧
#    - pages-seen.json        片中出现过的页面（页签聚类）
#    - pages-seen 不够时：python3 scripts/find_pages.py --video <视频> --out <目录>

# 3. 出图、标注、门禁
python3 scripts/stable_frame.py --video <视频> --time 00:11:40 \
  --window 4 --fps 6 --out chosen.png --report stable.json \
  --assert-region 500,340,1150,600 --assert-white-min 0.55
python3 scripts/annotate.py assets/annotations/manual.json --qa
python3 scripts/check_images.py --doc 手册.md --manifest assets/manifest.json \
  --require-page-id --min-width 1400 --report-out gate/image-gate.json --title-out gate/titles.jpg
python3 scripts/doc_lint.py --doc 手册.md --manifest assets/manifest.json \
  --images-dir assets/images --require-versioned --require-page-id \
  --annotations assets/annotations/manual.json --external \
  --report-out gate/doc-lint.json
```

**交付判定**：`check_images` 与 `doc_lint` 都 `ok`；缺图记入"证据缺口"表，不允许留空引用或编造截图。

## 三、录制语料要求（重点）

### 3.1 视频规格（硬性）

| 项 | 要求 |
|---|---|
| 分辨率 | ≥ 1920×1080；窗口不要缩放（浏览器 100%），不要录半屏/竖屏 |
| 帧率 | ≥ 25 fps（推荐 30 fps），不要用录屏软件的"省空间/低帧率"模式 |
| 编码 | H.264 MP4；码率 ≥ 4 Mbps（文字密集页面建议 8 Mbps） |
| 音频 | 48 kHz 单声道即可；讲解者用耳麦，避免环境噪声 |
| 画面完整性 | 浏览器**地址栏、页签栏、左侧菜单可见**；不要全屏隐藏界面 |
| 水印 | 不要出现录屏工具水印、共享屏幕水印、公司水印（后期脱敏成本高） |

### 3.2 操作节奏（决定截图质量）

1. **每步操作后停顿 1–1.5 秒**再继续（等动画结束、等数据加载完）。这是"稳定帧"能被抽到的前提。
2. **弹窗/抽屉出现后，停住**，让内容完整展开再说话；不要在淡入动画中继续操作。
3. 输入内容后**等待校验提示出现**再切页；避免"输入一半就切走"。
4. 页面切换后停 1 秒，让列表/图表渲染完成。
5. 不要用半透明浮窗、开发工具、通知横幅遮挡页面主体；录前关掉 IM/邮件通知。
6. 鼠标停靠在空白处，不要悬在关键字上；点击位置在控件中心。
7. 同一功能**只演示一次完整流程**；反复开关弹窗会产生大量过渡帧。

### 3.3 讲解要求（决定图文逻辑）

- 口述页面名与关键字段名（如"进入风险分析对象，点新增，编码必填"），便于证据锚点对齐。
- 每讲完一个功能，口述一句"这一步的结果是……"，方便结果页截图。
- 明确说明**不能演示/未开放**的功能，便于后续记"证据缺口"，不要默认演示过。
- 避免"这里点一下那里点一下"的碎片操作；按业务任务顺序录（配置→应用→结果→排查）。
- 如果想保留某页截图，**停留 2 秒以上**并保持页面静止。

### 3.4 录制顺序建议

按"模块菜单顺序 + 业务任务顺序"录：

1. 模块入口/菜单总览（证明菜单在哪）
2. 配置类页面（对象/单元/分类/排查库/巡检点/计划）
3. 业务操作（任务/隐患/奖惩）
4. 结果与报表（四色图/清单/三率一量/台账）
5. 设置与规则（流程设计/规则配置）

每段开始先说"现在看的是 XX 页面"，结束时说"这个页面就到这里"。

### 3.5 转写要求

- 优先使用**平台已有转写稿**；只有没有转写时才调用付费 ASR（`--no-whisper` 复用已有稿）。
- 转写稿要保留时间戳与说话人（若有多人）；剪辑/休息段要在交付时说明，避免时间轴对不上。
- 专业术语提前给"术语表"（如"巡检点"不是"学员点"、"三率一量"不是"三绿一良"），减少 ASR 错词。
- 若中途休息/暂停，录屏切成多个文件时，请附一份"文件与内容对应表"。

### 3.6 素材交付清单（录完给处理人）

- [ ] 视频文件（含时长、分辨率）
- [ ] 转写稿（若有）
- [ ] 术语表/缩写表
- [ ] 本批要覆盖的功能清单（页面级）
- [ ] 明确"不能演示"的功能清单
- [ ] 分段说明（如"上集 0:00–0:32，下集从 1:02 开始"）

## 四、截图与标注规范（处理人执行）

1. **稳定帧**：只用平台期帧；黑屏、加载中、过渡帧、重复帧一律弃用。
2. **浮窗**：浮窗是讲解对象 → 必须完整、不透明、可读；只是遮挡 → 换帧或裁掉；半透明/动画中 → 视为不合格。
3. **页面身份**：图注必须与 tab/弹窗标题一致；manifest 记录 `page_id`。
4. **脱敏**：默认只模糊**企业名称**（页面头部+组织树）；内网地址、手机号、共享水印如出现必须遮挡；项目另有要求从其要求并记录。
5. **标注**：只标操作点（按钮/输入框/下拉/tab/提交）；结果、报表、清单页不标；每图 ≤2 个；标签 2–8 字；箭头指向目标；编号与正文步骤一致。
6. **版本化**：文件名带 `-vN`，文档引用带版本；重生成后删旧文件，避免"看到的是旧图"。

## 六、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 截图弹窗半透明/字看不清 | 抽帧落在动画中 | 用 `stable_frame.py` 连拍重取；仍无清晰帧→记"需重录" |
| 文档里还是旧图 | 同名覆盖 + 查看器缓存 | 用 `-vN` 版本命名并更新引用；打开新文件 |
| 图注和页面对不上 | 抽错页面/步骤 | 核对 tab 与弹窗标题，修正图注或换图 |
| 某页面全片没有 | 录制时没打开 | 先查 `pages-seen.json`/页签扫描；确认没有→记缺口，不伪造 |
| 标注越标越多 | 没有标注策略 | 只标操作点，结果页不标；每图 ≤2 个 |
| 脱敏范围反复 | 没有默认口径 | 默认只遮企业名；项目特例写进门禁记录 |
